## ✨ О проекте

Одностраничный сайт-визитка консультанта по банковским продуктам. Тёмная «винная» палитра с золотыми акцентами, плавные анимации и адаптивная вёрстка на чистом HTML и CSS — без фреймворков и сборщиков.

Сайт помогает клиенту за пару минут понять, чем занимается консультант, какие услуги и по каким ценам он предлагает, и сразу написать в Telegram.

## 🎨 Особенности дизайна

- 🌑 **Тёмная тема** — глубокий фон `#0D0A11` с винными свечениями
- 🥇 **Золотые акценты** — градиенты и деликатные хайлайты
- 🎴 **Живой мокап карты** — наклон, свечение и блик при наведении
- ✨ **Появление блоков при скролле** — через `IntersectionObserver` с каскадной задержкой
- 📱 **Полная адаптивность** — от широких мониторов до небольших смартфонов
- ♿ **Уважение к настройкам** — анимации отключаются при `prefers-reduced-motion`
